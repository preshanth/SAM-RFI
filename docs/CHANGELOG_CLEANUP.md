# Training Workflow Cleanup - December 2024

## Summary

Cleaned up multiple conflicting training workflows and standardized on a single canonical path using the CLI.

## Changes Made

### 1. Removed Broken/Duplicate Code

**Moved to `deprecated/`:**
- `scripts/train_sam2.py` - Referenced non-existent `NumpyDataset`, used deprecated `.npz` format
- `scripts/run_training.py` - Duplicated CLI functionality with added complexity
- `configs/experiments/*.yaml` - All 4 experiment configs used deprecated `.npz` format

**Reason**: These files were incompatible with the current data generation pipeline which outputs batched `.pt` directories.

### 2. Fixed CLI Dataset Loading

**File**: `src/samrfi/cli.py`

**Before**:
```python
def load_dataset(path):
    if path.suffix == '.pt':
        return TorchDataset.load_from_disk(path)  # Expected single .pt file
    else:
        return load_from_disk(path)  # HuggingFace format
```

**After**:
```python
def load_dataset(path):
    if path.is_dir():
        metadata_file = path / "metadata.json"
        if metadata_file.exists():
            return BatchedDataset(path)  # NEW: Batched format
        else:
            return load_from_disk(path)  # Legacy HF format
    elif path.suffix == '.pt':
        return TorchDataset.load_from_disk(path)  # Legacy single file
```

**Impact**: CLI now correctly loads batched datasets (directories with `batch_*.pt` files).

### 3. Updated Validation Script

## Dataset Format Clarification

### Current Format (Batched Directories)

Generated by `samrfi generate-data`:

```
./datasets/train_4k/exact_masks/
├── batch_000.pt
├── batch_001.pt
├── ...
└── metadata.json
```

Each batch file contains:
- `images`: (N, 1024, 1024, 3) tensor
- `labels`: (N, 1024, 1024) tensor

### Legacy Formats (Still Supported)

1. **Single .pt file**: Old TorchDataset format
2. **HuggingFace directory**: Arrow tables with `dataset_info.json`

CLI auto-detects format based on file structure.

## Canonical Workflow

```bash
# 1. Generate data
samrfi generate-data --source synthetic --config configs/synthetic_train_4k.yaml --output ./datasets/train_4k
samrfi generate-data --source synthetic --config configs/synthetic_val_1k.yaml --output ./datasets/val_1k

# 2. Train with validation
samrfi train \
  --config configs/gpu_v100_training.yaml \
  --dataset ./datasets/train_4k/exact_masks \
  --validation-dataset ./datasets/val_1k/exact_masks

# 3. Predict
samrfi predict --model ./models/sam2_rfi.pth --input observation.ms --iterations 3
```

## Technical Notes

### BatchedDataset

- **Location**: `src/samrfi/data/sam_dataset.py:106`
- **Purpose**: Streaming dataset that loads `batch_*.pt` files on-demand
- **Benefits**: Low memory usage, parallel I/O, OS cache friendly
- **Used by**: CLI training command

### Kornia Dependency

- **Status**: Installed but not actively used
- **Purpose**: Intended for GPU-accelerated transforms to avoid I/O bottlenecks
- **Current**: Using pure PyTorch in `gpu_transforms.py`
- **Future**: May be used for additional optimizations

### NumpyDataset

- **Status**: Does not exist
- **Impact**: `scripts/train_sam2.py` was broken (now deprecated)
- **Replacement**: Use `BatchedDataset` via CLI

## Migration Guide

### If you were using `scripts/train_sam2.py`:

**Old**:
```bash
python scripts/train_sam2.py --config configs/experiments/exp1_synthetic.yaml
```

**New**:
```bash
samrfi train \
  --config configs/gpu_v100_training.yaml \
  --dataset ./datasets/train/exact_masks \
  --validation-dataset ./datasets/val/exact_masks
```

### If you were using `scripts/run_training.py`:

**Old**:
```bash
python scripts/run_training.py --config my_config.yaml
```

**New**:
```bash
# Generate data first
samrfi generate-data --source synthetic --config configs/synthetic_train_4k.yaml --output ./datasets/train

# Then train
samrfi train --config configs/gpu_v100_training.yaml --dataset ./datasets/train/exact_masks
```

### If you have old `.npz` datasets:

**Solution**: Regenerate using current pipeline:
```bash
samrfi generate-data --source synthetic --config configs/synthetic_train_4k.yaml --output ./datasets/new_train
```

Old `.npz` format is no longer supported.
